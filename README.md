## 🛠️ Cómo Compilar y Ejecutar

Para compilar y ejecutar cualquiera de los ejercicios desde la consola, sigue estos pasos:

1. Abre la terminal en la carpeta del ejercicio correspondiente.
2. Compila el ejercicio usando el comando `g++`:
   ```bash
   g++ main.cpp -o programa
   ```
3. Ejecuta el programa generado:
   * **En Windows:** `./programa`
